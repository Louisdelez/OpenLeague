## 5. Manques et reprises
- **MENUS-INPUT-PROVIDER** — Effective input provider/remap/priority and exact press/release semantics remain unqualified; two HUDEvents ini overrides are source-established only. Impact : Physical GameEvents ancestry cannot replace HUDEvents. Hold/toggle inferred from labels/names is not native dispatch proof. Reprise : Reuse shared five binding interfaces and Display AS init evidence; named native event caller or accepted local policy, then selected per-entry semantics.
- **MENUS-SCOREBOARD** — Configured O/Tab source to live authorized scoreboard display and hold/release lifetime are absent/unqualified in inspected consumers. Impact : Public roster/KDA and terminal result text do not implement a live board or authorize all native columns. Reprise : Existing SCORE-INPUT-01, LIVE-RENDER/END-TO-END plus per-column source/audience work; qualify one input/consumer profile, O/Tab interaction, focus lost and stale session.
- **MENUS-MOUSE-CLIP** — No current configured F9/evtToggleMouseClip or cursor-grab API consumer identified; original OS confinement lifecycle not established. Impact : Camera lock, drag ownership, Escape cancellation and F11 window mode do not confine/release OS pointer. Reprise : BIND-MENUS-MOUSE-CLIP-01: native callback/cycle or named local policy, one explicit window/backend and separate product/OS trial authorization.
- **MENUS-SYSTEM-CHARACTER** — System options and own-character-info open/close/apply/cancel/authority consumers remain open. Impact : Escape focus/cancel paths and C shop tests are present; no system menu/sheet completion. F3 debug and F11 mode not substitutes. Reprise : Reuse HUD-OPTIONS-ENTRY-01 and HUD-CHAMPION-INFO-ENTRY-01 with shared keymap and actual owner/session data; source native caller or explicit local policy before UI implementation.
- **MENUS-RUNTIME** — Physical keys/GUI/OS capture/focus/refusal and menu-rendered data not executed here. Impact : Static source/text and preserved prior isolated tests do not qualify real pointer release, native provider or menu display. Reprise : After named implementations/authorization, test5entries remap, layout, focus, UI priority, repetition/session/end and actual render/refusals; do not rerun unchanged native analyses.
