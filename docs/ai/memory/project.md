# OpenLeague

## Observations

- [scope] Recréer localement le jeu LoL 4.20, avec la Forêt torturée 3v3, le moteur Rust et le launcher historique en Rust/Tauri.
- [evidence] Les ressources récupérées, les valeurs natives, l'implémentation Rust et la qualification en exécution sont des étapes différentes.
- [policy] Les systèmes partiels et les reconstructions restent explicitement identifiés ; aucun pourcentage global n'est déduit du nombre de fichiers ou de tests.
- [sources] Le périmètre et les preuves détaillées sont dans docs/ROADMAP.md, docs/completion_plan.json, docs/coverage.json et docs/resume_checkpoint.json. Certains rapports et ressources ne sont disponibles que dans l'environnement de travail d'origine.
- [workflow] Lire les consignes du dépôt et les notes courtes docs/ai avant d'agir. Préserver les modifications existantes et les services locaux du chantier actif.
