## Écarts et reprise précise

1. Terminer `ITEM-3101-SCOPE` avant de décider si les tâches fonctionnelles conditionnelles doivent être exécutées ou exclues.
2. Pour conclure sur le texte produit, définir la langue attendue pour OpenLeague ; si elle doit suivre la référence EUW/en_GB, le consumer doit résoudre la ressource ou les clés correspondantes plutôt que supposer que le texte français du catalogue est équivalent.
3. Pour revendiquer un tooltip complet, vérifier séparément le nom, le prix de vente dynamique, les valeurs serveur, le markup et le texte des passifs dans le rendu de l’interface.
4. Reprendre le rendu natif seulement avec un résultat runtime/capture identifié et une politique de locale validée. Ne pas relancer les mêmes recherches de clés si ni le fichier natif, ni les données, ni le consumer ne changent.

Le chemin statique source → data → consumer et l’inclusion de 3101 dans la liste locale sont établis. L’équivalence fonctionnelle du tooltip n’est pas affirmée. La tâche `ITEM-3101-SHOP-TEXTE` reste `a_faire`, son audit ne clôt pas `ITEM-3101-SCOPE`, et SYS-01.2-02 reste actif et partiel.
