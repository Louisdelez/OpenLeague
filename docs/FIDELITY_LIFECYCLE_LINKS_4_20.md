Le nettoyage local à la mort ne qualifie pas toutes les persistances historiques. Le respawn normal ne prouve pas les résurrections ni transformations spéciales. Garen Q purge les ralentissements locaux ; cela ne qualifie pas Cleanse/QSS. La déconnexion legacy supprime le joueur après 30 secondes de silence ; la session reprenable détache la route et conserve le joueur tant que la session reste ouverte. Les contrôles expirent avec les ticks de simulation, le silence avec le temps hôte. Aucun équivalent historique de ces politiques locales n’est inventé.
