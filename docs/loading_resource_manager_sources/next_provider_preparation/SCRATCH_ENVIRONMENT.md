# Next isolated path environment — design only, not executed

Do not rerun the existing probe with unrestricted Windows imports. It deliberately refuses native `CreateDirectoryA` on D:. No full deployment copy is necessary.

Use a new root, for example `E:/mapslol3v3/loading_provider_io_probe/root`, with a virtual deployment at `root/RADS/solutions/lol_game_client_sln/releases/0.0.1.68/deploy`. Keep the same relative layout so native traversal toward manifests, Air and Config is exercised. `GetCurrentDirectoryA` must return this declared virtual deployment, not the Codex working directory or a guessed real game working directory.

Implement and log one explicit path resolver at the Win32 I/O boundary:

1. Decode only supported native ASCII paths. Normalize separators, resolve `.`/`..` against the declared virtual CWD, and reject requests outside the single virtual root. Resolve real filesystem paths and reject reparse-point escape before every write. Do not concatenate unchecked native strings into a shell command.
2. **Read-only mapping:** a virtual-root relative path maps to the same relative path under the original `League-of-Legends-4-20` root on D:. Attribute queries and enumeration call real Windows APIs; nonexistent paths return actual Windows failure. No generated folder list or success flag. Relative enumeration order stays Windows' actual order, unsorted. Log virtual path, physical source path, result and errors. Pin consumed file bytes by SHA256.
3. **Write mapping:** only an explicitly enumerated scratch subtree such as virtual `Config` is writable. Map it to its path under the new scratch root and invoke the real Windows API there. Record its actual return/error. All other write, create, truncate, rename and delete requests stop before execution. This includes writes through a handle originally opened for reading.
4. **Read after write:** accesses to a path already owned by the scratch write mapping resolve to scratch consistently. Do not report a source file as changed or merge source and scratch directory contents silently. If exact mixed enumeration becomes necessary, materialize the minimal required real files in that directory with recorded source/copy hashes and enumerate the physical scratch directory. Preserve an explicit mapping ledger.
5. **Handle safety:** actual read handles must be opened read-only; classify CreateFileA desired-access and creation-disposition flags before opening. Native 32-bit labels map to real host handles with their access class. Bound ReadFile buffers/counts; close actual handles on host cleanup. Unimplemented APIs remain a stopped boundary rather than generic success.

Config already exists in the original source root. The isolated environment must state which profile it executes: either copy only the genuinely required existing Config entries, with hashes, into scratch, or use an explicit initially empty scratch-Config profile. The latter is different from original startup and must not be called full startup parity. Do not create or alter D:/.../Config to make the probe progress.

The observed prefix only needs attributes on DATA, LEVELS, Air, the adjacent configurationmanifest/solutionmanifest and several absent candidates; no contents need copying for attribute-only operations. Preserve actual existence results through the read mapping. ToolsConfig.xml was absent at the deployment path inspected; the prior default-context constructor fragment still bypasses its XML decision, so this is not proof that all possible lookup roots lack it.

For the first successful character lookup, allow native reads of the real Ahri or Annie root and its Base directory. A minimal-copy alternative can copy only the selected `asset_inventory.json` INIBIN/DDS files and any subsequently observed required real dependency. Do not copy the entire deployment, fabricate missing defaults, substitute a hand-authored `.ini`, or answer a native resource callback from the JSON inventory. The provider must select the actual source through its own aliases and lookup flow.

Before this environment is considered usable, run a small isolation test proving that a native attempted write to the virtual source is reflected only in scratch, source hashes remain unchanged, an unsupported path stops, and real read errors are preserved. Then resume the PE at the genuine native entry in a fresh machine state; do not resume the abandoned call by injecting a success value. This environment and these tests are **not implemented or executed in this package**.
