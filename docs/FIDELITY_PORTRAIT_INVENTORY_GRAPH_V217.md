# SYS-01.2-02 — portraits et icônes reliés individuellement (V217)

Les 122 fiches de portrait de champion et les 33 fiches d’icône d’objet du catalogue courant relient maintenant le champ INIBIN natif, le DDS qu’il désigne, sa copie exacte et les fonctions qui la consomment dans le client Rust. Pour les champions, le champ est `Info/IconSquare` ; pour les objets, `Data/InventoryIcon`. Les 155 fichiers DDS courants sont identiques aux sources. Les 310 ressources natives (configurations et DDS) concordent avec les manifestes RADS sélectionnés.

Les consommateurs précis sont `native_hud_portraits::{source_panel,setup,selected,update}`, `native_hud_inventory::{values,sources,setup,icon_payloads,update_icons}`, le décodeur DDS commun, le chargement des atlas HUD et le constructeur de textures Nexus. Les liens génériques précédents sont conservés. Les deux tâches générales de traçabilité et de dépendances transitives reçoivent la collection complète, bornée à ces 155 associations.

Quatre tests Rust ciblés ont été réellement exécutés en V215 avec `cargo test --locked --offline` sous Rust 1.96.1 : portraits122, inventaire33/six emplacements, cinq atlas et deux textures Nexus. Chaque commande retourne 0 et un test passe ; 1542 autres tests sont filtrés à chaque commande. Journaux et reçus sont conservés. Les octets des outils et du binaire correspondent aux copies d’identité archivées en V214. Ces tests CPU ne constituent pas une observation GPU, une partie ni une validation de rendu.

Sept données erronées sont refusées par le contrôle de provenance. L’audit relit 157 sélecteurs, refuse quatre sélecteurs ou affectations incorrects, contrôle les 12 ancres et les identités ciblées. Les deux bases fournissent chacune les 157 fiches, textes copiables et traces attendus. Leurs 42606 états manuels et leur historique sont conservés ; les autres champs des tâches et les anciennes preuves sont inchangés. La validation globale est structurelle ; elle ne rehash pas toutes les sources du catalogue.

Limites : portraits de base seulement ; producteur natif AvatarImage, variantes de skin/forme, teinte de mort et équivalence framebuffer restent ouverts. Les 33 icônes ne couvrent pas tous les objets du patch. La grille de boutique utilise un PNG distinct du DDS d’inventaire. Le manifeste d’icônes mentionne encore32 dans son texte descriptif bien qu’il contienne33 entrées ; l’écart est enregistré sans modifier cette source. Le constructeur Nexus demeure non admis tant que ses prérequis ne sont pas réunis. Aucun état de complétion, champion ou jeu déclaré terminé.
